# s15-corteya

**CorteYa** es una plataforma digital diseñada para optimizar la reserva de citas en peluquerías. Permite a los clientes consultar horarios disponibles, seleccionar servicios y agendar o reprogramar sus citas de forma rápida, mientras ofrece al estilista una herramienta clara para gestionar y reorganizar su agenda de trabajo.
